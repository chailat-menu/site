# CHAILAT — электронное меню

Статический сайт меню кафе CHAILAT на казахском, русском и английском языках. Гости могут просматривать категории и блюда, добавлять позиции в корзину и показать список официанту. Сайт не отправляет заказы на сервер.

## Запуск

Сборка и установка зависимостей не нужны. Откройте `index.html` в браузере или запустите локальный статический сервер из корня проекта, например:

```bash
python -m http.server 8000
```

Затем откройте <http://localhost:8000>. Сервер удобен для проверки относительных путей к фотографиям. Шрифты Montserrat и Lora загружаются из Google Fonts; если сервис недоступен, используются системные запасные шрифты.

## Структура проекта

```text
index.html            Разметка, стили, меню, маршрутизация и логика корзины
i18n.js               Переводы интерфейса, описания категорий и названия блюд
photos/baner.jpeg     Фоновая фотография сайта
photos/global/        Широкие фотографии категорий на главной странице
photos/dishes/        Квадратные фотографии блюд
```

## Где менять содержимое

- **Блюда, цены и категории:** объект `CATS` в `index.html`. Каждое блюдо задаётся парой `[названиеНаКазахском, цена]`. Для блюда без опубликованной цены укажите `null`.
- **Разделы на главной:** массив `SECS` в `index.html`. Поле `cats` связывает раздел с одной или несколькими категориями из `CATS`.
- **Тексты и переводы:** `I18N`, `INTRO` и `DISH` в `i18n.js`. Для нового блюда добавьте в `DISH` перевод с ключом, точно совпадающим с его казахским названием из `CATS`; значения массива идут в порядке русский, английский. Если перевода нет, отображается исходное название.
- **Фотографии блюд:** объект `PHOTO_SETS` в `index.html`. Ключ — ID категории из `CATS`, значения — номера фотографий из `photos/dishes/` без ведущих нулей и расширения. Например, `39` соответствует `photos/dishes/dish-0039.jpg`. Номера сопоставляются с блюдами категории по порядку. Если точного снимка нет, можно указать ближайший подходящий. После изменения проверьте, что для каждого номера существует файл.
- **Фотографии разделов:** объект `BANNERS` в `index.html`; он сопоставляет ID раздела из `SECS` с файлом в `photos/global/`.
- **Контакты и ссылки:** объект `INFO` в `index.html`. Адрес задаётся отдельно для `kk`, `ru` и `en`; часы, телефон, Instagram и WhatsApp заданы рядом.
- **Сервисный сбор:** константа `SERVICE` в `index.html` (сейчас 12%). Текст сбора также переведён в `i18n.js`.

Сначала добавляйте изображение в соответствующую папку `photos/`, затем указывайте относительный путь от корня проекта. Имена файлов и пути чувствительны к регистру при публикации на Linux-хостинге.

## Как работает интерфейс

- Стартовая страница показывает группы разделов «Еда» и «Напитки». Выбор раздела меняет hash URL, например `#/s/breakfast`; переходы работают без перезагрузки.
- Переключатель языка меняет названия разделов, описания, интерфейс и доступные переводы блюд. Начальный язык — казахский; язык можно задать параметром `?lang=ru` или `?lang=en`.
- Состояние корзины и номер стола сохраняются в `localStorage` этого браузера под ключами `chailat_cart` и `chailat_table`. Они не синхронизируются между устройствами и не передаются кафе.
- Итог в корзине включает сумму блюд и сервисный сбор. Кнопка показа официанту переводит корзину в режим просмотра; посетитель показывает экран сотруднику.

## Публикация на GitHub Pages

Для публикации без сборки откройте настройки репозитория **Settings → Pages**, выберите источник **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните. После публикации сайт открывается по адресу GitHub Pages, указанному в настройках. Все файлы сайта, включая `index.html` и папку `photos/`, должны быть закоммичены в выбранную ветку.

## Перед коммитом

Проверьте, что пути и имена изображений совпадают с файлами, новые переводы добавлены во все нужные языки, а в `git status` нет локальных или временных файлов.
